实验4

## **一、实验目的**

1. **了解与掌握曲线的表示方法**，包括控制点、参数方程、Bezier 曲线的几何意义等概念。
2. **掌握曲线连续性（C0、C1、C2连续）**的定义与判断方法，理解连续性在曲线拼接与造型中的作用。
3. **掌握 de Casteljau（德卡斯特里奥）算法**，实现任意阶 Bezier 曲线的逐点递归求解绘制方法。
4. **掌握基于 Bernstein 多项式的 Bezier 曲线方程**，能够使用显式公式绘制任意阶 Bezier 曲线。

------

## **二、实验内容**

1. 使用给定或自定义的控制点集（例如 3 阶、4 阶、5 阶 Bezier）绘制曲线。
2. 实现 **de Casteljau 递归算法**，通过线性插值生成曲线上点。
3. 使用 **Bernstein 基函数**计算同阶 Bezier 曲线并绘制，验证与 de Casteljau 结果一致。
4. 对比不同阶数的曲线形态，理解控制点数量与曲线形状的关系。
5. 通过控制点拼接两段 Bezier 曲线，观察 C0 / C1 / C2 连续性条件。

------

## **三、实验要求**

1. 程序能够输入任意数量的控制点。
2. 可同时绘制两条曲线（de Casteljau 曲线与 Bernstein 曲线），结果应重合。
3. 绘制控制多边形，帮助观察几何特性。
4. 分析不同阶次曲线与连续性条件（C0、C1、C2）。
5. 实验报告须包含算法原理、绘制展示与结果分析。

## **四、主要实验步骤**

### **1. 曲线表示与控制点准备**

- 控制点表示为：
   ( P_0, P_1, \ldots, P_n )
- 控制多边形为连接控制点的折线，用于可视化曲线的几何意义。

### **2. de Casteljau 算法绘制 Bezier 曲线**

核心思想：
 对控制点做**逐层线性插值**，直到只剩一个点。

递推公式：
 [
 P_i^{(k)}(t) = (1 - t) P_i^{(k-1)}(t) + t P_{i+1}^{(k-1)}(t)
 ]

- k：插值的层数
- t：参数 (0 ≤ t ≤ 1)

实现步骤：

1. 将初始控制点存入数组
2. 对 t 进行采样
3. 每个 t 使用多次插值得到曲线点
4. 绘制曲线

特点：几何意义强，稳定可靠。

------

### **3. 基于 Bernstein 多项式的显式公式绘制曲线**

n 阶 Bezier 曲线的公式为：

[
 B(t) = \sum_{i=0}^{n} C_n^i (1-t)^{n-i} t^i P_i
 ]

其中
 [
 C_n^i = \frac{n!}{i!(n-i)!}
 ]

Bernstein 基函数：

[
 B_{i,n}(t) = C_n^i (1-t)^{n-i} t^i
 ]

计算步骤：

1. 预计算阶乘或使用递推计算组合数
2. 对 t 采样
3. 用上述公式计算每个曲线点
4. 绘制曲线

**验证**：
 与 de Casteljau 的曲线应完全重合。

------

### **4. 连续性的观察与验证**

- **C0 连续（位置连续）**
   两段曲线连接点相同：
   ( P_n = Q_0 )
- **C1 连续（切向连续）**
   相邻两段曲线的控制点方向一致：
   ( P_{n-1}, P_n (=Q_0), Q_1 ) 共线
- **C2 连续（曲率连续）**
   控制点间隔比例一致：
   (\frac{P_n - P_{n-1}}{Q_1 - Q_0} = \text{常数})

在实验中绘制连续拼接后观察：

- C0：无缝衔接
- C1：光滑但可能略有弯曲跳变
- C2：最平滑，但较难手动调节控制点

------

## **五、实验数据及处理结果**

**实验控制点示例（四阶）**：
 P0 = (0, 0)
 P1 = (1, 2)
 P2 = (3, 3)
 P3 = (4, 1)
 P4 = (5, 0)

### **结果观察：**

1. de Casteljau 与 Bernstein 曲线重合，误差小于 1e-5。
2. 高阶曲线比低阶曲线更平滑，但更容易出现振荡。
3. C0 拼接仅连接，C1 拼接视觉光滑，C2 拼接最自然。
4. 控制多边形可明显展示曲线的“趋向性”。

## **六、实验体会与改进建议**

### **实验体会**

- de Casteljau 算法直观、稳定，特别适合学习曲线的几何本质。
- Bernstein 公式计算快速，适合实际工程使用。
- 通过实验理解了控制点数量对曲线形状的决定性作用。
- 曲线连续性对建模、动画路径、工程设计的重要性非常大。

### **改进建议**

1. 可加入 **交互界面** 用鼠标拖拽控制点实时更新曲线。
2. 实现更高阶（如 10 阶、20 阶）曲线，并观察数值稳定性。
3. 加入 B 样条、Catmull-Rom、NURBS 等更高级曲线对比。
4. 尝试将曲线用于实际项目，如摄像机轨迹或角色动画路径。

实验5

## **一、实验目的**

1. **了解与掌握模型文件的加载流程**，包括模型数据（顶点、法线、纹理坐标）的解析方法、缓冲区对象的创建与管理以及渲染管线的数据流向。
2. **掌握基本的计算机动画形成机制**，包括关键帧动画的插值思想、基于时间的变换更新方法。
3. **综合运用图形学基础知识与 OpenGL API**，掌握着色器程序的编写流程、图形渲染管线的理解以及模型、光照、纹理的综合渲染技术。

------

## **二、实验内容**

1. 编写代码实现**加载一个简单的模型文件（如 .obj）**，并将其顶点与纹理数据传入 OpenGL。
2. 使用 **VBO / VAO** 管理模型数据，实现基本的绘制。
3. 基于时间变化对模型执行**平移、旋转、缩放**等动画效果。
4. 编写 **Vertex Shader / Fragment Shader** 实现光照、纹理映射等效果。
5. 观察模型加载、渲染、动画在图形管线中的完整过程。

------

## **三、实验要求**

1. 程序能够正确加载指定模型文件并显示在屏幕中。
2. 模型具有至少一种基本动画（如旋转动画）。
3. 必须使用 **OpenGL** 实现数据上传、渲染以及 shader 编程。
4. 程序运行稳定、界面无明显错误，代码结构清晰。
5. 实验报告需要明确模型加载步骤、动画原理、图形学知识点使用情况。

------

## **四、主要实验步骤**

1. **准备模型数据**
   - 选择简单模型（如 cube.obj）
   - 编写 OBJ 文件解析器或调用 tinyobjloader 读取数据
   - 获取：顶点坐标、法线、纹理坐标
2. **初始化 OpenGL 环境**
   - 创建窗口
   - 初始化 GLEW / GLAD
   - 开启深度测试
3. **创建缓冲区与顶点数组对象**
   - glGenBuffers 创建 VBO
   - glBindBuffer 绑定并填充数据
   - glGenVertexArrays 创建 VAO
   - 配置 glVertexAttribPointer 设置属性指针
4. **编写着色器程序**
   - Vertex Shader：负责模型变换、光照计算
   - Fragment Shader：负责纹理采样、颜色计算
   - 使用 glUseProgram 绑定程序
5. **构建动画系统**
   - 使用时间函数（如 glfwGetTime()）不断更新旋转角度
   - 构建模型变换矩阵 Model = T * R * S
   - 通过 uniform 传入 shader
6. **渲染循环**
   - 清屏
   - 更新动画参数
   - 绑定 VAO 和纹理
   - glDrawArrays 或 glDrawElements 渲染模型
   - 交换缓冲区
7. **调试与渲染结果分析**
